# Security reports

Do not publish credentials, private paths, saves, raw dumps or working exploit details in public issues. Use the repository Security tab's **Report a vulnerability** option for a private report. Include the affected commit, impact, minimal reproduction and a proposed fix if available, using synthetic data.

Only the current research source is maintained; there is no supported gameplay release yet. This project does not provide security guarantees for unvalidated builds or offsets. For ordinary bugs use the public bug form with a sanitized summary.
